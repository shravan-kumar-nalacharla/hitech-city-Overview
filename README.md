# 🏢 HITEC City 3D — Project Management Case Study Presentation

An interactive, 3D WebGL presentation deck analyzing the planning, governance, public-private partnership (PPP) structuring, risk management, and long-term urban impact of the **151-Acre HITEC City Greenfield Township Development** in Madhapur, Hyderabad.

## 🌟 Key Features
- **3D WebGL Interactive Scene (Three.js)**: Continuous auto-rotating 3D model of Cyber Towers with real-time studio lighting and customizable camera views.
- **151-Acre GIS Map Border Polygon**: Pulsing red 3D boundary ribbon outlining the entire 151-acre township parcel layout on the masterplan terrain grid.
- **10 Fact-Checked Presentation Deck Slides**:
  1. **Case Study Overview**: Inception stats, $15B+ IT exports, 10 Lakhs+ workforce.
  2. **Project Charter**: Formal mandate, vision, scope inclusion/exclusion boundaries, governance authority.
  3. **Stakeholder Power–Interest Matrix**: 2D 6Sigma pastel color-coded grid with zero text overlap.
  4. **PPP Governance Hierarchy**: 4-level org chart with explicit SVG connector branch edges.
  5. **Perimeter Infrastructure & 4 Gates**: Gate 1 Front Entrance, Gate 2 Front Exit, Gate 3 Rear Parking, Gate 4 Logistics Service Bay.
  6. **Project Lifecycle Timeline**: 4-phase execution history (1996–Present, 14-month fast-track build).
  7. **Risk Register (R-01 to R-10)**: Categorized risk matrix with PMI PMBOK (7th ed.) mitigation strategies.
  8. **Expansion Roadmap (2024–2035)**: Kokapet Neopolis, AI University, Airport Express Metro, Net-Zero carbon township target.
  9. **Key Project Outcomes & Legacy**: Strategic synthesis & academic references.
  10. **Summary & Glossary**: Full forms of acronyms (PPP, SPV, APIIC, HMDA, STPI, EPC, SEZ, APSEB, PMI PMBOK) and **Thank You** closing banner.
- **Performance Optimization**: `🏙️ City Map: ON / OFF` toggle for solid 60+ FPS performance.

cd hitech-city-Overview

# Start local server
npm start
